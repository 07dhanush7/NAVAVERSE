Frontend-Only Demo

Job Applications Route to the Job Creator

Jobs store createdBy. Applications store receiverId = job.createdBy. Dashboards only show applications where receiverId === currentUser.id.

Current Session

Switch users to test admin-created jobs and user-created jobs.

Routing Rule

  1. Fetch the job using jobId.
  2. Read job.createdBy.
  3. Save receiverId = job.createdBy.
  4. Show only matching applications in the dashboard.
